# Pattern: Specialist Team

Use specialist roles when recurring work benefits from independent expertise without pretending the project is a company hierarchy.

Example:

```text
Main Claude
├── Architecture Reviewer
├── Research Specialist
└── QA / Verification Reviewer
```

Each specialist must pass the CPOA agent test: a stable recurring question, distinct ownership, and real benefit from separate context, mandate or permissions.

Prefer this pattern when functional expertise describes the work more accurately than executive titles.
